## ⚙️ Setup

To run these programs on your computer, follow these steps:

1. **Install VS Code** (if not already installed)  
   [VS Code Download](https://code.visualstudio.com/)

2. **Install C/C++ Extension**  
   - Open VS Code → Extensions → Search for `C/C++` (by Microsoft) → Install  

3. **Install Code Runner Extension** (optional, for easy running)  
   - Open VS Code → Extensions → Search for `Code Runner` → Install  

4. **Install a C++ compiler**  
   - **Windows:** MinGW or TDM-GCC  
   - **Mac:** Xcode Command Line Tools (`xcode-select --install`)  
   - **Linux:** `sudo apt install g++`  

5. **Run your programs**  
   - Open the `.cpp` file in VS Code → Right-click → **Run Code** (if using Code Runner)  
   - Or compile manually using terminal:
     ```bash
     g++ filename.cpp -o filename
     ./filename      # Linux/Mac
     filename.exe    # Windows
     ```
